# 接口限流接入

能力边界、身份语义、统计保留与运维标准以[接口限流](../../../../docs/backend/rate-limit.md)为准。

1. 先判断入口防滥用、认证后身份保护、开放套餐配额或出站连接器限速的职责，禁止合并计费与入站保护。
2. 内置默认规则只在 shared/platform/rate-limit-policy.ts 定义，seed及运行时共用；自定义规则复用配置接口，不在GET初始化规则。
3. 路径/方法规则与诊断使用 shared/platform/rate-limit.ts 同一匹配器；需要业务具名保护时复用 namedRateLimit，并登记具名挂载来源。
4. 身份只读取已验证认证上下文，不自行解JWT或按请求自报ID计数；公开令牌只做不可逆资源摘要，展示路由模板。
5. 数据库、shared契约、校验、Service、域hooks、页面、Demo与权限seed同时更新；变更配置缓存订阅时同步迁移触发器。
6. 业务预期失败与Redis故障区分，503明确标识；维护响应不能与限流不可用混淆。限流命令必须有界，统计异步有界且允许观测丢弃。
7. 按文档验收矩阵执行真实Redis和双实例验证，最后进行桌面及窄屏浏览器回归；只更新当前规范，不写改造历史。
