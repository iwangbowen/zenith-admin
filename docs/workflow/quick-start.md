# 快速开始与角色入口

工作流引擎的菜单按审批中心、流程管理和运维与集成分组。先按自己的角色选择入口，再沿下列路径完成一次发起、审批或配置。

## 发起人与审批人

1. 进入「工作流引擎 → 审批中心 → 发起工作台」，选择当前有权发起的已发布流程。外部业务主导流程从对应业务模块提交。
2. 填写表单，查看预计审批路径；需要自选审批人的分支在提交前选择。可先保存草稿，也可直接提交。
3. 在「我的申请」查看状态、流转记录和实际审批链。退回待修改的申请在原实例修改重提；被驳回或撤回的普通申请按流程设置创建新草稿。
4. 审批人在「待我审批」按任务处理。同一实例的并行待办各自成行，实际可用动作取决于当前节点的按钮、意见、附件和签名配置。
5. 在「我已办」查看自己的处理记录，在「抄送我的」查看送达记录。审批单打印另需打印权限。

发起工作台显示六张概览卡片：待我审批、待我协办、抄送未读、退回待修改、我的草稿和审批中。超时数量显示在待办卡片内；无对应列表权限的卡片不显示。

手机浏览器可进入 `/approval.html` 使用移动审批。移动端支持表单库流程发起及高频审批动作，能力范围见[移动审批轻页](./mobile-approval.md)。

## 流程管理员

1. 在「流程管理 → 表单库」准备表单，或确定使用自定义表单 / 业务系统主导表单。
2. 在「流程定义」新建流程，配置发起范围、表单来源、节点、分支、处理人和更多设置。也可从「流程模板」创建草稿。
3. 使用发布前体检和仿真检查结构、处理人、分支与阻塞点，修复严重问题后发布。
4. 按需要配置流程自动化，或使用定时发起按计划生成申请。

具体配置见[流程定义与设计器](./designer.md)、[节点配置](./node-config.md)、[表单设计与运行时](./form-design.md)、[流程自动化](./automations.md)和[定时发起](./schedules.md)。

## 运维与集成管理员

| 入口 | 用途 |
| --- | --- |
| 流程监控 · 实例监控 | 查看流程状态、实例详情和运行时诊断，执行授权范围内的实例干预 |
| 流程监控 · 任务监控 | 按任务查询滞留与处理记录，对待办催办 |
| 流程监控 · 作业账本 | 查看异步作业、执行尝试和链路，处理死信与重放 |
| 流程监控 · 引擎诊断 | 查看执行组件、队列、健康趋势与恢复预览 |
| 健康巡检 | 根据阈值定位异常任务、Token 和实例 |
| 事件订阅 / 触发器执行 | 查看外部投递或触发器的执行记录 |
| 连接器 / 远程数据源 | 管理外呼通道与表单远程选项 |

发现异常后，先查实例、任务、Token 和作业事实，再选择催办、改派、恢复或重放。外部写请求结果不明时需先确认接收方结果。操作权限与查询范围见[权限与范围控制](./permissions.md)，排查步骤见[监控、诊断与运维](./monitoring-operations.md)。
