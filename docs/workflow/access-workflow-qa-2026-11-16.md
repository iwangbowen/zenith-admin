## API 与 worker 验收

- 自动批准、主管审批、高风险主管加安全审批、极高风险三人独立审批及当次 MFA。
- 驳回及撤回不发权；逐项撤权不影响同包其它项；无关用户读取实时结果返回拒绝，申请人不能重试治理发放。
- 预约授权开始前不可用；永久授权失效时间为 null；短期授权到期状态更新；复核延期更新真实授权项。
- 独立普通办公流程完成审批，且不会出现在权限发放记录。
- 故障仅针对本次申请，触发器和函数在脚本 finally 中清除；恢复后检查任务成功与授权唯一性。
