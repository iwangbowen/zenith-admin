# 任务监控

任务监控是流程监控中的跨实例任务视图，用于从任务角度定位待办滞留和处理负载。入口为「工作流引擎 → 运维与集成 → 流程监控 → 任务监控」，需要 `workflow:instance:monitor` 权限，并受租户与角色数据范围控制。

## 查询与统计

页面支持按流程名称 / 申请标题关键字、审批人关键字、节点类型、任务状态、停留阈值和任务创建时间筛选。停留阈值可选 30 分钟、2 小时和 24 小时，只匹配尚未结束的任务。列表优先展示 `pending`，其次为 `waiting`，再显示终态任务。

顶部卡片统计当前租户和角色数据范围内的全部任务，统计不受列表关键字、时间等筛选条件影响；点击状态卡片会切换列表的状态条件。接口还支持按 `definitionId` 或 `instanceId` 限定查询。

节点类型包括审批、办理、抄送、延迟、触发器和子流程。抄送任务送达后状态为 `skipped`，界面显示“已抄送”；等待任务需要结合等待原因判断是在等待顺序会签、加签、外部审批、子流程、延迟还是触发器。

## 任务详情与处置

列表展示申请标题、流程与单号、发起人、发起时间、节点、任务开始 / 结束时间、审批人、状态、意见、耗时和任务编号。「详情」打开该任务所属的实例详情；`pending` 任务提供催办入口，催办仍受服务端限频控制。

任务监控不替代实例级强制跳转、批量恢复和作业重放。需要改写执行位置时，转到[监控、诊断与运维](./monitoring-operations.md)执行带原因留痕的实例操作；需要查看异步作业时，查看同页的作业账本。

## 与其它入口的边界

| 入口 | 主要对象 | 典型用途 |
| --- | --- | --- |
| 待我审批 | 当前用户的人工任务 | 处理审批、办理、协办 |
| 我已办 | 当前用户已经处理的任务 | 查询个人处理历史 |
| 任务监控 | 授权范围内的跨实例任务 | 定位积压、等待和处理负载，含人工及自动节点任务 |
| 实例监控 | 流程实例 | 查看流程整体状态并执行实例级操作 |
| 作业账本 | 异步作业与执行尝试 | 定位延迟、外呼、事件和自动化作业故障 |
