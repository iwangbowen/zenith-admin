# 移动审批轻页

移动审批轻页是面向手机浏览器的独立 SPA，覆盖「查看待办 → 审批 → 发起申请」的高频移动场景。它与管理后台共享登录态，无需重复登录。

## 入口

| 入口 | 说明 |
| --- | --- |
| `/approval.html` | 独立 SPA 入口（Vite 多入口构建，与后台 `index.html` 并存） |
| 后台头像菜单 → 移动审批 | 从管理后台快捷打开轻页 |
| `/approval.html#/login` | 未登录时的登录页；登录态与后台共享 |

路由使用 **HashRouter**（多入口零 rewrite）：

| 路由 | 页面 |
| --- | --- |
| `#/` | 任务列表（TabBar 主页） |
| `#/detail/:instanceId`、`#/detail/:instanceId/:taskId` | 审批 / 实例详情 |
| `#/launch` | 发起申请（流程选择） |
| `#/launch/:definitionId` | 发起表单填写 |
| `#/login` | 登录 |

## 底部标签栏

主页采用主流 App 底部 TabBar（图标 + 文字 + 角标），中间为凸起「发起」按钮：

| 标签 | 内容 |
| --- | --- |
| 待办 | 待我处理的审批任务，显示待办数角标 |
| 已办 | 我已处理的任务，卡片展示我的处理结果 |
| 我的申请 | 我发起的实例 |
| 抄送我 | 抄送任务和未读标记；一键已读只处理当前已加载列表中的未读任务 |

## 待办处理

| 能力 | 说明 |
| --- | --- |
| 搜索 | 待办、已办和抄送列表支持关键字查询；「我的申请」不传关键字筛选 |
| 下拉刷新 | 手势刷新列表 |
| 极速同意 | 列表卡片直接同意，无需进入详情 |
| 批量同意 | 勾选 / 全选多条待办批量通过；允许复用签名的任务可一次确认个人模板；要求本次手写、自选下一审批人、必填附件等任务自动置灰 |
| 连续审批 | 详情提交后自动进入下一条待办，无需返回列表 |

## 审批详情

详情页包含发起人头像块、审批进度提示和底部操作抽屉：

| 能力 | 说明 |
| --- | --- |
| 表单展示 | 按当前节点字段权限过滤 `hidden` 字段；`edit` 字段可直接修改并随「同意」提交（仅表单库表单）；自定义业务表单 / 业务系统主导流程以只读模式渲染业务查看组件 |
| 同意 / 驳回 / 转办 | 底部操作抽屉承载动作、意见、下一节点审批人选择和转办接收人；同意按钮配置附件必填时提示到桌面端处理 |
| 手写签名 | 与桌面端共用个人签名：允许复用时确认使用模板或重新手写，要求本次手写时只能重写 |
| 快捷短语 | 快速填入常用审批意见 |
| 沟通评论 | 查看并发送文本评论；发送时不提供 @提及、附件或引用回复 |
| 发起人操作 | 发起人可撤回运行中的申请、对待办催办 |

`external` 业务查看组件使用当前审批的 `instanceId` 读取业务资料，服务端校验实例与业务键关联及当前人的流程可见性；组件只显示业务内容，流程状态和审批进度由移动详情页统一承载，避免嵌套桌面抽屉。业务模块自己的预览与往次流程入口见[业务接入规范](./business-integration.md)。

移动端与后台使用同一账号的签名模板和版本。打开同意操作时按当前任务的策略确认签名，不把上一条任务的签名选择自动用于下一条；个人模板变更或删除后，过期引用需要刷新重选。批量同意逐条显示成功/失败原因，部分失败不隐藏在成功提示中。模板管理与证据规则见[我的签名](../iam/profile.md)，完整批量限制见[审批操作](./approval.md#批量处理)。

## 发起申请

- 流程选择页支持搜索和「最近使用」快捷入口。
- 表单填写复用与桌面端同源的表单渲染规则（显隐、条件必填）。
- 发起时的「自选审批人」与审批中的「转办」均内置移动端人员选择器（搜索 + 头像多选底部抽屉）。
- 只有表单来源为 `designer` 的流程支持移动端发起；`custom` / `external` 流程在移动端审批与详情可只读查看业务表单内容。

## 与管理后台的能力范围

| 能力 | 移动审批 | 管理后台 |
| --- | --- | --- |
| 发起申请 | 表单库表单 | 表单库或自定义表单；业务系统主导流程从业务模块发起 |
| 审批时编辑 | 当前节点可编辑的表单库字段 | 表单库字段或自定义表单声明的可编辑变量 |
| 处理动作 | 同意、驳回、转办 | 同意、驳回、转办、委派、加减签、退回与协办等 |
| 签名 | 按当前任务策略确认个人模板或本次手写 | 同一签名契约与证据规则 |
| 审批附件 | 操作要求必填时转到管理后台处理 | 按按钮附件策略上传 |
| 打印与分享 | 复用 PDF 接口和打印权限 | PDF 预览、打印、下载及批量导出 |

打印来源、归档件与验真见[审批单打印与存证](./print-and-archive.md)。

## 体验细节

- 页面切换带过渡动画，移动优先样式。
- 登录态与后台共享；token 失效时跳转 `#/login`。
- 桌面端完整能力（委派、加签、减签、退回、协办等）见[审批、任务与协作](./approval.md)。
