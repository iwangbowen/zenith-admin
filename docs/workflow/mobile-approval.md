# 移动审批轻页

移动审批轻页是面向手机浏览器的独立 SPA，覆盖「查看待办 → 审批 → 发起申请」的高频移动场景。它与管理后台共享登录态，无需重复登录。

## 入口

| 入口 | 说明 |
| --- | --- |
| `/approval.html` | 独立 SPA 入口（Vite 多入口构建，与后台 `index.html` 并存） |
| 后台头像菜单 → 移动审批 | 从管理后台快捷打开轻页 |
| `/approval.html#/login` | 未登录时的登录页；登录态与后台共享 |

路由使用 **HashRouter**（多入口零 rewrite）：

| 路由 | 页面 |
| --- | --- |
| `#/` | 任务列表（TabBar 主页） |
| `#/detail/:instanceId`、`#/detail/:instanceId/:taskId` | 审批 / 实例详情 |
| `#/launch` | 发起申请（流程选择） |
| `#/launch/:definitionId` | 发起表单填写 |
| `#/draft/:instanceId` | 本人草稿或退回申请编辑 |
| `#/statistics` | 审批统计（需流程监控权限） |
| `#/login` | 登录 |

## 底部标签栏

主页采用主流 App 底部 TabBar（图标 + 文字 + 角标），中间为凸起「发起」按钮：

| 标签 | 内容 |
| --- | --- |
| 待办 | 待我处理的审批任务，显示待办数角标 |
| 已办 | 我已处理的任务，卡片展示我的处理结果 |
| 我的申请 | 我发起的实例 |
| 抄送我 | 抄送任务和未读标记；一键已读只处理当前已加载列表中的未读任务 |

## 待办处理

| 能力 | 说明 |
| --- | --- |
| 搜索与筛选 | 待办、已办、我的申请、抄送均支持服务端关键字查询、流程/优先级/状态筛选；筛选条件写入 URL，返回列表时恢复标签、筛选和滚动位置 |
| 下拉刷新 | 手势刷新列表 |
| 极速同意 | 列表卡片直接同意，无需进入详情 |
| 批量同意 | 勾选 / 全选多条待办批量通过；允许复用签名的任务可一次确认个人模板；要求本次手写、自选下一审批人、必填附件等任务自动置灰 |
| 连续审批 | 详情提交后自动进入下一条待办，无需返回列表 |

## 审批详情

详情页包含发起人头像块、审批进度提示和底部操作抽屉：

| 能力 | 说明 |
| --- | --- |
| 表单展示 | 按当前节点字段权限过滤 `hidden` 字段；`edit` 字段可直接修改并随「同意」提交（仅表单库表单）；自定义业务表单 / 业务系统主导流程以只读模式渲染业务查看组件 |
| 审批与协作动作 | 底部操作条与抽屉承载同意、驳回、转办、委派、前/后/并加签、退回、协办、撤回已办、动态抄送；按任务能力隐藏不可用动作，动作附件支持 hidden/optional/required 策略 |
| 手写签名 | 与桌面端共用个人签名：允许复用时确认使用模板或重新手写，要求本次手写时只能重写 |
| 快捷短语 | 快速填入常用审批意见 |
| 沟通评论 | 查看并发送评论，支持 @提及、附件与引用回复 |
| 发起人操作 | 发起人可撤回运行中的申请、对待办催办 |

`external` 业务查看组件使用当前审批的 `instanceId` 读取业务资料，服务端校验实例与业务键关联及当前人的流程可见性；组件只显示业务内容，流程状态和审批进度由移动详情页统一承载，避免嵌套桌面抽屉。业务模块自己的预览与往次流程入口见[业务接入规范](./business-integration.md)。

移动端与后台使用同一账号的签名模板和版本。打开同意操作时按当前任务的策略确认签名，不把上一条任务的签名选择自动用于下一条；个人模板变更或删除后，过期引用需要刷新重选。批量同意逐条显示成功/失败原因，部分失败不隐藏在成功提示中。模板管理与证据规则见[我的签名](../iam/profile.md)，完整批量限制见[审批操作](./approval.md#批量处理)。

## 发起申请

- 流程选择页支持搜索和「最近使用」快捷入口。
- 表单填写复用与桌面端同源的表单渲染规则（显隐、条件必填）。
- 发起时的「自选审批人」与审批中的「转办」均内置移动端人员选择器（搜索 + 头像多选底部抽屉）。
- 表单来源为 `designer` 的流程支持移动端发起；已注册移动创建组件的 `custom` 流程（当前为「权限申请」）同样可在移动端发起，其余 `custom` / `external` 流程在移动端审批与详情可只读查看业务表单内容，或由业务模块提供移动入口。
- 草稿支持标题、表单值、优先级、发起抄送、发起人自选与表单版本引用；编辑时校验 `draftRevision`、流程版本和表单 revision，冲突会要求重新确认。新建申请在首次输入后写入本地恢复稿，服务端草稿自动保存；退出或身份切换会清理恢复稿。

## 与管理后台的能力范围

| 能力 | 移动审批 | 管理后台 |
| --- | --- | --- |
| 发起申请 | 表单库表单 + 已注册移动创建组件的自定义表单（权限申请） | 表单库或自定义表单；业务系统主导流程从业务模块发起 |
| 审批时编辑 | 当前节点可编辑的表单库字段；自定义业务表单按业务动作组件处理 | 表单库字段或自定义表单声明的可编辑变量 |
| 处理动作 | 同意、驳回、转办、委派、加减签、退回、协办、撤回已办、动态抄送 | 同意、驳回、转办、委派、加减签、退回、协办、撤回已办、动态抄送等 |
| 签名 | 按当前任务策略确认个人模板或本次手写 | 同一签名契约与证据规则 |
| 审批附件 | 按动作附件策略拍照/相册/文件上传 | 按按钮附件策略上传 |
| 打印与分享 | 复用 PDF 接口和打印权限 | PDF 预览、打印、下载及批量导出 |

打印来源、归档件与验真见[审批单打印与存证](./print-and-archive.md)。

## 体验细节

- 页面切换带过渡动画，移动优先样式；底部操作条适配安全区，长表单与签名/附件抽屉占满可用高度。
- 登录态与后台共享；token 失效时跳转 `#/login`。会话按用户/租户隔离，切换账号会清空查询缓存、最近使用、滚动位置和本地恢复稿。
- 列表使用服务端分页与筛选，滚动到底自动加载下一页；从详情返回保持原 Tab、筛选条件和滚动位置。
- 连续审批默认开启，处理完自动进入下一条本人待办，并提示剩余数量；可在详情底部关闭。
- 草稿详情提供继续编辑、提交申请和删除；保存后保持编辑态。恢复稿使用应用内提示，离开前确认；退回申请提供“修改并重新提交”，保留原实例和业务编号。
- 详情提供申请内容、审批进度、沟通锚点；完整时间线按需加载，评论每次展示 20 条。底部操作条和抽屉根据 Visual Viewport 避让键盘；设备行为仍需真机验收。
- 权限申请支持权限搜索、模块折叠和吸顶已选汇总，长清单默认收起；PDF 系统分享失败可退回保存文件。
- 桌面端完整能力（委派、加签、减签、退回、协办等）见[审批、任务与协作](./approval.md)。

## 审批通知

移动入口只显示通知目录 `workflow` 分组的站内信，包含待办、流程结果、退回、抄送、协办、催办及流程评论提及。CPU、磁盘、通用作业等系统告警保留在后台收件箱；维护和会话失效仍由独立提示处理。

- 投递保存结构化 `eventKey`，分组由共享通知事件目录派生，不按标题、来源、链接或语气推测归属。不回填或兼容历史无事件键消息。
- 列表、未读数、全部已读共用服务端 `eventGroup` 过滤，并同时限制本人和租户范围；先过滤再计数、分页，移动端每页 20 条。
- 全部已读作用于全部符合条件的审批通知，包含尚未加载的页；不改变其它分组或其它收件人的消息。与后台共享同一条消息的已读状态。
- 范围已读的 WebSocket 回执携带分组，后台重新读取剩余未读数，不把全站未读误清零。通知未读与待办任务数独立。

## 管理员统计

工作台顶部的统计入口及独立页面按 `workflow:instance:monitor`（或 `*`）开放，服务端仍独立校验权限。复用流程监控的分析、全局实例、待办监控和超时预警契约，查询使用审批端请求实例及当前会话缓存。统计与预警按当前租户、操作数据范围和流程定义筛选；汇总读取使用同一个只读快照。

- 指标：实例总数（含草稿）、运行中实例、待办任务、已超时任务；点击指标可查看分页明细并进入实例。
- 概览：24 小时内即将超时、近 168 小时创建、已完结实例平均耗时；近 14 个业务自然日趋势、状态分布、流程分布和节点积压。
- 实例与任务分别计数；创建包含草稿。沿用现有监控口径，完结含通过、驳回、撤回和取消，耗时及完结日使用当前终态更新时间；不将其宣称为事件账本的历史统计。
- 超时沿用已到期且仍待执行的 `task_timeout` 作业口径，不代表所有历史 SLA 违约。汇总和下钻的查询时刻不同，处理中的记录可能变化。
- 该版本不提供移动端强制终止、改派等管理写操作；入口权限不赋予审批他人任务的权限。
