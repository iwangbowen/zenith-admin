# 物联网

物联网能力覆盖产品与设备管理、设备接入、分组、遥测、告警、自动化、远程控制、OTA 与第三方数据转发。设备接入和后台管理共用 Server，但使用不同的认证入口。

## 能力入口

| 能力 | 当前用途 |
| --- | --- |
| 产品与设备 | 管理设备类型、设备身份、生命周期与所属产品 |
| 设备分组 | 按业务或部署关系组织设备，支持批量操作 |
| 数据接入 | 接收设备遥测并将数据映射到设备状态与时序记录 |
| 告警与自动化 | 按设备状态和规则处理告警，触发自动化动作 |
| 远程管理 | 批量控制、计划任务与固件 OTA 由异步任务执行 |
| 数据转发 | 将选定设备数据转发到外部目标 |

## 运行边界

- 管理 API 位于 `packages/server/src/routes/iot/`，业务规则位于 `packages/server/src/services/iot/`。
- 设备接入使用 IoT 专用注册和 ingest 路由，不复用管理员或会员会话。
- 需要耗时、批量或可重试的操作提交到统一任务中心，任务状态与进度在任务中心查看。
- 设备数据的读取范围由服务端权限、租户归属和设备可见性校验执行。
- 物模型管理使用当前租户视角校验产品访问权。设备、产品、分组与所属网关须同租户。分组关联在设备或分组的写入事务中校验并更新。

## 开发入口

共享契约位于 `packages/shared/src/iot/`，管理页面位于 `packages/web/src/pages/iot/`。API 操作与响应以共享契约和运行中的 `/api/docs` 为准。新增设备类型、接入字段或异步操作时，按 Zenith Skill 同步契约、服务端、前端、权限、seed 与 Mock。
