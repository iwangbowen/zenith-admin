## 第三轮：业务审批、附件与归档

锚点扩展到 28 类。请假单、CMS 内容、对账调整单接入历次审批与流程反查；审批附件和归档件可从业务单据或流程查看，附件还可回到所属审批任务。原业务页按主键精确打开，流程只展示实际所属的业务分组。

### 文件模型

- 新增 `workflow_attachment_uploads`、`workflow_attachment_links`，通过文件 FK、任务/评论与实例的复合 FK、来源约束和唯一约束保证绑定身份。
- 输入只接受 `fileId`；服务端生成名称、大小、类型、绑定 ID 和受控 URL，不解析旧 URL。
- 上传使用 restricted/private；绑定、释放、引用计数与审批动作、评论、表单写入在同一事务。重提、子流程、回调及自动化表单修改纳入同一入口。
- 下载校验租户、流程参与者和字段权限。归档原件额外检查节点隐藏字段与 PII 脱敏，明确请求 archive 并校验 SHA-256。
- 报表复用表单渲染器时显式采用 public 附件协议；移动审批和已有流程上传携带实例上下文。
- 迁移 `0008_funny_paibok.sql` 已在本地执行。调整了生成器输出顺序，先建立被引用的复合 UNIQUE，再创建 FK。
