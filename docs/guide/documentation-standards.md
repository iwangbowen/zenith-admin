# 文档维护规范

文档站描述当前代码、配置和运行方式，读者应能按页面内容完成对应操作。

## 内容边界

- 架构文档维护稳定的系统边界、目录职责、依赖方向和运行时链路。
- 开发文档维护当前命令、配置、契约、测试和验收方式。
- 业务专题维护当前可用能力、权限边界、数据口径、接口入口和部署依赖。
- 产品文档维护当前能力地图和推荐阅读路径。
- 版本变更记录属于发布记录，不作为开发规范、架构规范或业务操作手册的依据。

## 当前标准

- 只写当前有效的规范和实现，不为已经移除的方案保留操作说明。
- 不在规范页面描述版本迁移过程、历史实现、旧接口或已废弃配置。
- 命令、端口、环境变量和脚本以根 `package.json`、工作区 `package.json`、`.env.example`、Docker 文件和 CI 工作流为准。
- 能力清单以当前路由注册、菜单种子、前端页面、Service 和共享契约为准。
- 代码模板和硬约束以 `.agents/skills/zenith/` 为准，文档站只提供入口、边界和使用说明。
- 页面引用其他文档时链接到当前规范的唯一入口，避免复制同一规则形成多个版本。

## 更新检查

文档改动至少完成以下检查：

```bash
npm run docs:build
```

涉及命令、配置、路由或业务能力时，还应对照对应代码和配置文件检查示例。新专题应登记到 `docs/.vitepress/config.mts`，并在相关总览页提供入口。
