# 企业网盘

企业网盘为组织提供个人、部门和协作空间，把目录、权限、版本、外链与回收站放在同一套管理流程中。
文件对象复用[文件与存储](../storage/index.md)底座，访问权限由网盘服务执行。

管理后台的「企业网盘」包含我的网盘、共享空间、空间治理、外链治理、动态审计、合规治理和网盘设置。
访客通过 `/public/drive/:token` 进入公开外链页；第三方应用经开放平台 `/api/open/v1/drive/*` 访问被授权的空间。

## 当前能力与边界

支持目录浏览、拖拽上传、分片续传、受权限约束的秒传、历史版本、外链密码 / 次数 / IP 白名单、文件收集链接、
访问申请审批、二维码与短链、预览水印、到期提醒、在线状态、签出锁定、标签、评论、收藏、最近访问和文本检索。治理概览展示最近 **7 天**趋势。

治理与集成能力：法律保留（冻结删除与跨空间移动）、空间归档（只读可恢复）、容量趋势与扩容审批、外链访问日志导出、
异常行为告警（批量下载 / 外链爆破）、租户级设置覆盖、开放 API 与文件变更 Webhook（按空间授权）、发送到聊天与 Wiki 引用链接。

网盘不依赖任何外部服务：不做 Office / PDF 正文抽取与服务端渲染、不做在线编辑与 AI 问答、不接病毒扫描或 DLP，
这些也不在后续规划中。异常行为告警是内置阈值规则，不是行为分析引擎。

**未交付项**：WebDAV 网关与 Electron 桌面同步客户端本阶段未实现——两者都需要自实现协议 / 同步引擎并长期维护，与现有
开放 API（可完成目录浏览、下载与上传）相比投入产出不匹配，暂不纳入；如需程序化访问，请使用开放 API 与 Webhook。
工作流侧没有专用的「网盘文件」表单字段类型，表单可用 `url` 字段引用网盘链接。

::: warning 预览边界
目前在线预览仍会把文件内容发送到浏览器。「仅预览」限制下载入口和显式下载接口，
不能防止访客保存已收到的内容；预览水印是前端覆盖层，用于抑制随手截图外传。两者都不能视为 DRM 或防复制保障。
:::
