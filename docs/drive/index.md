# 企业网盘

企业网盘为组织提供个人、部门和协作空间，把目录、权限、版本、外链与回收站放在同一套管理流程中。
文件对象复用[文件与存储](../storage/index.md)底座，访问权限由网盘服务执行。

管理后台的「企业网盘」包含我的网盘、共享空间、空间治理、外链治理、动态审计和网盘设置。
访客通过 `/public/drive/:token` 进入公开外链页。

## 当前能力与边界

支持目录浏览、拖拽上传、分片续传、受权限约束的秒传、历史版本、外链密码 / 次数 / IP 白名单、文件收集链接、
访问申请审批、二维码与短链、预览水印、到期提醒、在线状态、签出锁定、标签、评论、收藏、最近访问和文本检索。治理概览展示最近 **7 天**趋势。

网盘不依赖任何外部服务：不做 Office / PDF 正文抽取与服务端渲染、不做在线编辑与 AI 问答、不接病毒扫描或 DLP，
这些也不在后续规划中。WebDAV 与桌面同步属于后续阶段，不是仅增加数据模型就已经可用的功能。

::: warning 预览边界
目前在线预览仍会把文件内容发送到浏览器。「仅预览」限制下载入口和显式下载接口，
不能防止访客保存已收到的内容；预览水印是前端覆盖层，用于抑制随手截图外传。两者都不能视为 DRM 或防复制保障。
:::
