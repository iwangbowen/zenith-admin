# 企业网盘

企业网盘为组织提供个人、部门和协作空间，把目录、权限、版本、外链与回收站放在同一套管理流程中。
文件对象复用[文件与存储](../storage/index.md)底座，访问权限由网盘服务执行。

管理后台的「企业网盘」包含我的网盘、共享空间、空间治理、外链治理、动态审计和网盘设置。
访客通过 `/public/drive/:token` 进入公开外链页。

## 当前能力与边界

支持目录浏览、拖拽上传、分片续传、受权限约束的秒传、历史版本、外链密码与次数限制、
签出锁定、标签、评论、收藏、最近访问和文本检索。治理概览展示最近 **7 天**趋势。

文件收集、Office 服务端渲染与在线编辑、AI 问网盘、DLP、WebDAV 和桌面同步仍属于后续阶段，
不是仅增加数据模型就已经可用的功能。

::: warning 预览边界
目前在线预览仍会把文件内容发送到浏览器。「仅预览」限制下载入口和显式下载接口，
不能防止访客保存已收到的内容；不能将其视为 DRM 或防复制保障。
:::
