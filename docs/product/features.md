# 功能模块

本文基于当前代码实现整理，主要对照后端 22 个路由领域、共享层业务域、菜单种子、前端页面与 MSW Mock。

## 路由领域口径

领域数量以 `packages\server\src\routes\index.ts` 的 `ROUTE_DOMAINS` 为准，由 `packages\server\src\app.ts` 逐域挂载。当前注册顺序为：

```text
ops、identity、member、platform、files、tasks、analytics、report、messaging、payment、
open-platform、workflow、chat、mp、biz-demo、ai、short-link、marketing、iot、cms、wiki、drive
```

这里统计的是路由领域，不是 API 前缀、共享层目录或菜单分组；例如 `rules`、`licensing` 由 `platform` 挂载，不另计领域。新增或移除注册项时，应同步更新本节与对应专题入口。

| 路由领域 | 专题文档 | 边界 |
| --- | --- | --- |
| `platform` | [平台基础能力](../platform/index.md) | 系统配置、字典、地区、标签、反馈、安全治理、监控、缓存与实时通道，也负责规则和 License 路由装配 |
| `files` | [文件与存储](../storage/index.md) | 通用文件、业务附件与存储配置；共享契约位于 `shared\src\platform\contracts`，专题沿用 `/storage/` |
| `drive` | [企业网盘](../drive/index.md) | 空间、目录、协作权限、版本与外链；复用 `files` 存储底座 |

## 跨模块共性能力

### 权限与访问控制

- 管理员与会员是隔离的认证上下文、请求实例和会话语义。
- 菜单与按钮权限分离，动态菜单按用户权限加载。
- 数据权限由服务端执行，支持全部、自定义、本部门、本部门及以下、仅本人等范围。
- 多租户通过服务端 `tenant_id` 隔离；平台超管可切换租户视角。

### 请求安全防护

- 接口限流使用 Redis。
- 幂等控制基于 Redis `SET NX EX`，支持 `X-Idempotency-Key` 与自动指纹模式。
- CSRF 校验 `Origin`，生产通过 `ALLOWED_ORIGINS` 配置。
- 报表、AI、开放平台 Webhook 等出站请求具有私网 / 本机 allowlist 控制。
- 文件上传做 Magic Bytes 检测。

### API 与数据规范

- 响应信封：`{ code, message, data }`。
- 分页结构：`{ list, total, page, pageSize }`。
- OpenAPI + Zod 校验，请求参数通过路由校验后进入 service。
- 时间字符串统一 `YYYY-MM-DD HH:mm:ss`。

### 多入口前端

- `index.html`：后台管理。
- `member.html`：会员前台。
- `approval.html`：移动审批。
- Electron 模式切换为 `HashRouter`。
- Demo 模式由 MSW 替换 API 边界。

### 实时与可观测

- WebSocket：通知、Chat、终端等实时通道。
- SSE：服务监控、AI 流式等场景。
- 健康检查：`GET /api/health`。
- 指标采集：`GET /metrics`。
- Trace：可选 OpenTelemetry OTLP 导出。

### 文档与调试

- Swagger UI：`/api/docs`。
- OpenAPI JSON：`/api/openapi.json`。
- Mastra Studio：`/studio/`，生产需要登录与 `ai:studio:access`。
- Demo 站：`/demo/`，由 GitHub Pages 工作流从 MSW 构建产物合并发布。
